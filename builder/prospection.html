Remplir les stages et les cours 🐴

Tous les organismes susceptibles d'envoyer des jeunes à l'académie, avec leurs contacts. Pour chacun : cliquez « ✉️ Envoyer la présentation », votre messagerie s'ouvre avec le mail déjà rédigé au nom de l'organisme, il n'y a qu'à appuyer sur Envoyer. Puis notez où vous en êtes avec le statut. Tout est enregistré dans ce navigateur.

✉️ Le mail de présentation

C'est le texte envoyé à chaque organisme. Modifiez-le librement : il est conservé. Astuce : si vous écrivez {organisme} quelque part, c'est remplacé automatiquement par le nom du contact. Le mail renvoie vers la page « Groupes & collectivités » du site, votre vitrine pour les partenaires.
