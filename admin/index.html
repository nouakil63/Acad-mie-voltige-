          Comment traiter une demande ?

          Pour un stage, validez la demande pour envoyer le lien de paiement de l’acompte. Pour un cours, validez puis appelez la famille : vous pourrez ensuite enregistrer le créneau et envoyer les informations de paiement. Un refus envoie un message avec le motif choisi.

          Stripe

          Stripe est en attente d’activation. Le rapprochement et les remboursements seront disponibles une fois la connexion vérifiée.

          Échéances et modalités de règlement

          Pour les stages : acompte de 300 € à l’inscription, puis solde au plus tard 30 jours avant le début du stage. Le trimestre de cours est dû indépendamment des présences. Déclarer un remboursement dans le dossier n’effectue aucune opération bancaire. Les encaissements affichés restent bruts ; un remboursement n’annule pas automatiquement l’inscription.
